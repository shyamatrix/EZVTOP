# EZVTOP

EZVTOP is a premium, lightning-fast web portal wrapper designed specifically for students to view and organize their academic data in a clean and beautiful interface. 

---

## Features

- **Attendance Tracker**: View comprehensive semester and day-wise attendance statistics.
- **Grades & Marks Inspector**: Access detailed mark breakdowns, course grades, and historical CGPA summaries.
- **Exam Schedules**: Seamless export of exam details to calendar formats.
- **Hostel Portal**: Keep track of mess details, laundry quotas, and leave history.
- **Cloud Storage**: Secure and temporary local file transfers.

---

## Tech Stack

- **Frontend**: Next.js 16, React 19, Tailwind CSS v4, Framer Motion, Jotai
- **Backend**: Express, MongoDB, Backblaze B2, Nodemailer

---

## Getting Started

### Local Development

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start the Development Server:**
   ```bash
   npm run dev
   ```

3. **Start the Backend API:**
   ```bash
   npm run api-dev
   ```
